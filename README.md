# YB 교육 전후 설문

교육 전·후 효능감 설문을 진행하고 변화를 자동 분석해 교육생에게 즉석에서 보여주는 웹앱입니다.

- 관리: https://youngbaekim.github.io/survey/
- 교육생 응답: `s.html?id=교육ID` (QR로 안내) · 공개 결과: `r.html?id=교육ID`

## 실행 방법 (PowerShell)

```
cd C:\dev\survey
npm install      # 처음 한 번만
npm run dev      # 개발 서버 실행 → 화면에 나오는 주소를 브라우저로 열기
```

- 종료: PowerShell 창에서 `Ctrl + C`
- 배포: `main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포

## 처음 설정 (한 번만)

| 순서 | 할 일 |
|---|---|
| 1 | [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트 `yb-survey` 만들기 (애널리틱스 불필요) |
| 2 | 빌드 → **Firestore Database** → 데이터베이스 만들기 (위치 `asia-northeast3` 서울, 프로덕션 모드) |
| 3 | 빌드 → **Authentication** → 시작하기 → 로그인 방법 **Google** 사용 설정 |
| 4 | Authentication → 설정 → **승인된 도메인**에 `youngbaekim.github.io` 추가 |
| 5 | 프로젝트 설정 → 내 앱 → 웹 앱(`</>`) 추가 → 표시되는 설정값을 `src/firebase-config.js`에 붙여넣기 |
| 6 | Firestore → **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 게시 |
| 7 | GitHub에 `survey` 저장소 생성 → Settings → Pages → Source를 **GitHub Actions**로 지정 |

## 사용 순서

| 단계 | 관리 화면 | 교육생 |
|---|---|---|
| 준비 | ＋ 새 교육 → 설정·문항(척도, 효능감 문항, 회고적 사전 평가, 만족도·주관식) 저장 | — |
| 교육 전 | 진행 탭 → ① 사전 설문 열기 → 발표 모드로 QR 띄우기 | QR 접속 → 응답 코드(생일 4자리+휴대폰 끝 2자리) → 응답 |
| 교육 후 | ② 사후 설문 열기 | 같은 화면이 자동 전환 → 응답 → **나의 결과** 즉시 확인 |
| 결과 공유 | 결과 공개 켜기 → 발표 모드 ‘결과’ | 나의 결과에 전체 평균 표시, 전체 결과 보기 |
| 정리 | 결과 탭 → CSV 내려받기, A4 인쇄·PDF / 주관식 탭 | — |

## 문항 입력 형식

| 구분 | 형식 | 예 |
|---|---|---|
| 객관식(단일) | `질문 \| 보기1, 보기2, …` | `소속 \| 교원, 직원, 기타*` |
| 객관식(복수) | 질문 끝에 `(복수)` | `관심 분야(복수) \| 수업, 연구, 행정` |
| 직접입력 보기 | 보기 끝에 `*` | `기타*` → ‘기타(직접입력)’ |
| 기타 문항 세트 | 설정 탭 ＋/－ 버튼 | 화면 표시 이름·실시 시점(사전/사후/사전·사후) 지정 |

## 분석 방법

| 항목 | 내용 |
|---|---|
| 분석 대상 | 같은 응답 코드로 사전·사후 모두 제출한 응답(짝지어진 응답) |
| 검정 | 대응표본 t검정, Wilcoxon 부호순위 검정(n ≤ 50 정확 검정, 초과 시 정규 근사) |
| 효과크기 | Cohen's d<sub>z</sub> = 평균 차이 ÷ 차이의 표준편차 (0.2 작음 / 0.5 중간 / 0.8 큼) |
| 회고적 사전 평가 | 사후에 ‘교육 전의 나’를 함께 응답 → 회고적 사전 vs 사후, 실제 사전 vs 회고적 사전(응답 이동) |
| 주관식 | 원문 목록 + 핵심어 단순 빈도 |
| 검증 | 통계 함수는 scipy 1.18 결과와 대조(40개 사례, t·p·d<sub>z</sub>·Wilcoxon 일치) |

## 개인정보·보안

- 이름 등 식별정보를 수집하지 않으며, 응답 코드는 `SHA-256(교육ID|코드)` 앞 20자로만 저장됩니다.
- 교육생은 응답 제출(열린 단계만, 수정 불가)과 공개 집계 읽기만 가능, 응답 목록·원자료는 관리자만 조회합니다.
- 짝지어진 응답이 최소 공개 인원(기본 5명) 미만이면 교육생에게 집계를 공개하지 않습니다.
- 한계: 응답 코드가 6자리 숫자이므로, 같은 교육 주소를 아는 사람이 코드를 대입해 특정 코드의 응답 문서를 조회하는 것은 막지 못합니다(이름 없음, 점수만 노출).
- 공개용 집계는 관리 화면(해당 교육)이 열려 있는 동안 자동 갱신됩니다.
